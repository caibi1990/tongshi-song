# 英语听力音频目录

english.html 会从这里按固定路径加载音频：

```
public/audio/english/
├── unit1/
│   ├── ready_go.mp3      # Ready Go  热身导入
│   ├── letters.mp3       # Letters   字母拼读
│   ├── words.mp3         # Words     核心单词
│   ├── communicate.mp3   # Communicate 情景对话
│   ├── story.mp3         # Story     故事听力
│   └── extend.mp3        # Extend    拓展延伸
├── unit2/ ... unit6/     (同结构)
└── wordlist.mp3          # 全册单词总表
```

原始文件名（如 `U1 Ready go.MP3`）需按上面规则重命名归类。
音频缺失时页面会提示「这节音频还没准备好」，不会报错崩溃。
